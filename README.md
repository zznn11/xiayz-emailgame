# 夏以昼 · 邮件批改小游戏

一个纯前端的小游戏：你是那个替夏以昼批改邮件的人。
读完一封信，回一封——措辞、态度、分寸都得自己拿。

## 怎么玩

- 在线：<https://zznn11.github.io/xiayz-emailgame/>
- 本地：把仓库下载下来，双击 `index.html` 就能开，不用装任何东西。

## 文件

- `index.html` —— 页面骨架
- `main.js` —— 邮件内容、批改逻辑、结局判定
- `style.css` —— 样式

没有依赖、没有后端，纯 HTML + JS + CSS。
